# Design Preparation Prompt

Prepare a draft design for <game-id> using templates/GAME_DESIGN.md and docs/GAME_CATALOG.md. This is documentation work only; do not implement the game.

Preserve the owner's concept. Separate confirmed decisions, proposed defaults and unresolved questions. Specify complete rules, state transitions, private/public information, controller/display interaction, edge cases and worked examples. Identify contradictions rather than silently resolve them. Keep prototype scope bounded and list later expansions separately.

Leave status draft and approval NOT APPROVED. The owner must explicitly approve the version before implementation. After approval, update the catalog/status and create a bounded feature specification linked to that version.
